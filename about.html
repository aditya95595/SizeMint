ABOUT SIZEMINT

Simple image compression, built for the browser.

SizeMint is a lightweight web utility for reducing image file sizes to practical targets such as 100KB, 200KB or 1MB. The project is designed around a simple idea: give people a clear file-size target and let the browser do the work without requiring an image-upload backend.

How it works

Your browser decodes the selected image and draws it to a local canvas. SizeMint tests encoder quality and, when needed, reduces dimensions until the result fits the requested target as closely as the selected format allows. The final file is created as a browser Blob and offered for download.

Why target bytes instead of a quality number?

Quality percentages are difficult to compare across formats and images. A quality value that produces a small photograph on one image may produce a much larger file on another. A target size gives you a concrete constraint that is useful for upload forms and systems with byte limits.

Supported formats

JPG/JPEG, PNG, WebP and AVIF inputs are accepted when the browser can decode them. Output options are WebP, JPG and PNG. PNG is lossless, so its quality behavior is different from lossy formats.

Privacy approach

The core compressor does not require an image-upload endpoint. Selected image contents are processed in the browser during normal use. The site can still receive ordinary technical web requests through its hosting provider, and advertising services may process information when advertising is enabled. See the Privacy Policy for the current disclosure.

Project support

SizeMint is maintained as a small independent web project. If you find a bug or have a feature request, you can report it through the project's public issue tracker.

Limitations

Exact file sizes are not always possible because browser encoders, image content and dimensions vary. SizeMint reports the final result rather than guaranteeing an exact byte count. You should keep an original copy of important images before compression.

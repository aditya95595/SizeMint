ABOUT SIZEMINT

Simple image compression, built for the browser.

SizeMint is a lightweight utility for reducing image file sizes to practical targets such as 100KB, 200KB or 1MB.

How it works

Your browser decodes the image and draws it to a local canvas. SizeMint tests encoder quality and, when needed, reduces dimensions until the result fits the requested target as closely as the selected format allows.

Why browser-based?

The compressor does not need a file-upload backend, so image data can remain on your device during normal use.

Supported formats

JPG/JPEG, PNG, WebP and AVIF inputs are accepted when the browser can decode them. Output options are WebP, JPG and PNG.

Limitations

Exact file sizes are not always possible because browser encoders differ and image content affects compression. PNG is lossless, so its quality setting cannot work like JPEG quality.

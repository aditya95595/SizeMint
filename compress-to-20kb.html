Compress image to 20KB, exactly.

Forms ask for "under 20KB", not "80% quality". Here is how to hit an exact 20KB target without the guesswork.

Worth knowing before you start

We made 20KB a one-click preset because it kept coming up: exam forms, government portals, job applications. The honest truth is that 20KB is a tight budget for a photograph, and this guide does not pretend otherwise — here is what actually helps.

Reducing dimensions beats lowering quality. A 1600-pixel photo squeezed to 20KB looks worse than an 800-pixel photo at the same 20KB. Fewer pixels means every byte carries more of the image, so shrink first and compress second.

Convert PNG screenshots to JPG for small targets. PNG is lossless, which makes it a poor fit for tiny file sizes. The same 20KB goes much further as a JPG — use SizeMint's format option rather than fighting the PNG.

Match the format the form asks for, not just the size. A 19KB file can still be rejected if the portal expects JPG and you hand it a PNG. Check the required format in the form's instructions before you compress.

When you need exactly 20KB

A 20KB limit usually comes from an upload form: exam registrations, government portals, job applications and visa systems. These systems check the byte count mechanically — 21KB fails just like 2MB does. The reliable approach is to name the target first and let the tool work toward it, instead of nudging a quality slider and re-checking the size after every attempt.

How to compress to 20KB in SizeMint

1. Upload your image

Open the SizeMint compressor and drop in a JPG, PNG, WebP or AVIF file. Processing happens entirely in your browser — the image is never uploaded anywhere.

2. Enter 20 as the target

Type 20 KB as the target size. The compressor searches encodings automatically to find the best quality that fits under 20KB, rather than applying one fixed quality setting and hoping.

3. Inspect the result honestly

20KB is a very small budget for a photograph. Check faces, text and edges at full size. If the image looks unacceptably degraded, the honest fix is to reduce dimensions first and then compress — fewer pixels need fewer bytes.

4. Download and verify

Download the result and confirm the file size in your file manager before uploading it to the form. Keep your original — a 20KB file is a submission copy, not an archive.

What 20KB can and cannot do

A simple graphic or a small cropped photo can reach 20KB and still look clean. A detailed 12-megapixel photograph cannot keep all its detail at 20KB — physics wins. If your form allows a range like 20–50KB, target the middle (around 35KB) for visibly better quality with the same acceptance rate.

Format matters too: for photographs, JPG is the safest choice because older portals sometimes reject WebP. See JPG vs WebP vs PNG for the full comparison.

If the target cannot be reached

Some images contain too much fine detail — foliage, hair, fabric texture — for any encoder to squeeze into 20KB at usable quality. A responsible tool reports this instead of silently handing back an oversized file. When that happens: shrink the dimensions, try again, and judge the result at the size it will actually be displayed.

Questions, answered

Is 20KB enough for a clear photo?

For a small passport-style photo, usually yes. For a detailed full-resolution photograph, 20KB means visible softness — that is physics, not the tool failing. Judge the result at the size it will actually be displayed, not zoomed in.

Why JPG and not WebP for a 20KB target?

WebP is technically the better format, but some older government and exam portals only accept JPG and reject anything else outright. When a form is involved, use the format it names. For general web use, WebP at 20KB will look better than JPG.

My file is 21KB — will the form accept it?

Usually not. These systems check the byte count mechanically, and 21KB fails a 20KB limit the same way 2MB does. Target slightly under — 19KB — so small differences in how sizes are measured do not push you over.

What if nothing I try reaches 20KB?

Reduce the image dimensions and try again. Fine detail is what costs bytes: foliage, hair, fabric texture. A smaller image at 20KB almost always looks better than a large one squeezed to the same size — and keep your original, since the 20KB file is a submission copy, not an archive.

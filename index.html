IMAGE COMPRESSION EXPLAINED

Why compress an image to a target size?

Upload limits are often the annoying part of an otherwise simple task. A photo that looks perfectly fine on a phone can still be several megabytes because modern cameras and phones capture large dimensions and preserve a lot of detail. Reducing the file size can make uploads easier, reduce storage requirements and improve page-loading performance.

Instead of guessing a quality percentage, SizeMint lets you start with the limit you actually need. Choose a target such as 100KB or 500KB, and the browser encoder searches for a practical result. If the selected settings cannot reach the requested size, SizeMint reports that instead of pretending an exact result was achieved.

Which image format should you use?

JPG

Useful for photographs and other images with many colors. It uses lossy compression and is widely supported.

WebP

A modern general-purpose format that often produces smaller files than JPG at comparable visual quality.

PNG

Best when lossless image data or transparency is important. PNG does not respond to the quality slider like JPG or WebP.

AVIF input

SizeMint can accept AVIF files when the browser can decode them, while output choices remain WebP, JPG or PNG.

How to choose a target

For email attachments and simple document uploads, 100–500KB can be a practical starting range. For website images, the right limit depends on the dimensions, subject and visual quality you need. A small thumbnail can often be much smaller than a full-width photograph. There is no universal “correct” file size, so compare the downloaded result at the size where it will actually be displayed.

Privacy by design

The core compressor uses browser APIs to read, decode and encode the selected files. There is no SizeMint image-upload endpoint. That means normal compression can happen without sending the image contents to a SizeMint server. Read the Privacy Policy for information about hosting and future advertising technologies.

FAQ

Common questions

Does SizeMint upload my images?

No. The core compressor reads and processes selected images in your browser. It does not require an image-upload endpoint.

Can it guarantee an exact file size?

No. File size depends on image content, dimensions, browser encoders and the selected format. SizeMint searches for a result at or below the target where possible and reports when it cannot reach it.

What happens with PNG?

PNG is lossless, so the quality slider cannot reduce PNG data in the same way as JPEG or WebP. If a small target is important, WebP or JPG may be more suitable for photographs.

Can I compress several images?

Yes. Select multiple images and SizeMint processes them one by one in your browser.

What is the maximum input size?

Each selected file is limited to 25MB, and very large image dimensions are rejected to reduce the risk of excessive browser memory use.

Will compression change image dimensions?

It can. You can set an optional maximum width, and SizeMint may reduce dimensions when necessary to reach a difficult target.

Does SizeMint keep my original files?

The browser uses the selected files during the current session. SizeMint does not need a server-side image storage system for the compressor.

Can I use the results commercially?

SizeMint is a processing tool, not a source of image rights. You are responsible for having the necessary rights or permissions for the images you process and publish.

FAQ

Common questions

Does SizeMint upload my images?

No. Compression happens in your browser using the Canvas API.

Can it guarantee an exact file size?

File size depends on image content, dimensions and format. SizeMint searches for a result at or below the target where the browser encoder allows it, then reports when the target could not be reached.

What happens with PNG?

PNG encoding is lossless, so the quality slider has little or no effect. Automatic or WebP usually gives the browser more room to reduce size.

Can I compress several images?

Yes. Select multiple images and SizeMint processes them one by one in your browser.
